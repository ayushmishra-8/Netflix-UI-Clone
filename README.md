# 🎬 Netflix UI Clone

A Netflix-inspired frontend UI built using **HTML and CSS**.
This project focuses on recreating the visual layout and user interface of a streaming platform.

## 🚀 Live Demo

[View Live Demo](https://netflix-ui-clone-fpp1tr0v2-ayushmishraofficial9-3674s-projects.vercel.app/)

## 📂 GitHub Repository

[View Source Code](https://github.com/ayushmishra-8/Netflix-UI-Clone)

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Netflix-inspired homepage UI
* Responsive layout
* Navigation bar
* Hero section with background video
* Content sections and movie/show cards
* Custom favicon
* Images and video assets
* Deployed using Vercel

## 📁 Project Structure

```text
Netflix-UI-Clone/
│
├── assets/
│   ├── images/
│   └── videos/
│
├── favicon.ico
├── index.html
└── style.css
```

## 💻 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/ayushmishra-8/Netflix-UI-Clone.git
```

2. Open the project folder:

```bash
cd Netflix-UI-Clone
```

3. Open `index.html` in your browser.

## 📌 Project Purpose

This project was built to practice and strengthen frontend development fundamentals, particularly **HTML structure, CSS styling, layouts, positioning, and responsive design**.
